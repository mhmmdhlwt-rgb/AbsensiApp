# Pesantrenku Phase 3 - Uji Sebelum Deploy

Paket ini dibuat dari arsip stabil dan berada di folder terpisah. Tidak ada perubahan pada Firebase project atau data produksi saat paket dibuat.

## Cek Akademik

1. Buka Akademik, pilih program, lalu daftarkan evaluasi.
2. Tambah catatan akademik dan pilih lebih dari satu santri.
3. Buka profil salah satu santri lalu tab Catatan. Bagian Akademik harus menampilkan hasil evaluasi.
4. Export satu evaluasi dan export program. File program harus memiliki satu sheet per evaluasi.

## Cek Keuangan

1. Tambah tagihan dengan pilihan seluruh santri aktif.
2. Dari daftar tagihan tekan ikon tambah di kolom Catat.
3. Ambil foto atau pilih bukti pembayaran, lalu simpan.
4. Pastikan tautan bukti muncul di sheet Pembayaran ketika export keuangan.

## Cek Operasional

1. Di Pelanggaran, centang beberapa data lalu selesaikan atau hapus secara massal.
2. Di Santri, coba filter kelas sekolah, kelas diniah, dan komplek.
3. Di Pengaturan, isi komplek untuk kamar. Pastikan santri kamar tersebut ikut mendapat nilai komplek.
4. Ubah Jenis Asrama menjadi putra. Kontrol Uzur harus tidak tampil dan pencatatan Uzur baru ditolak.
5. Pada ponsel, buka formulir panjang dan sentuh input paling bawah. Input harus discroll ke area yang terlihat di atas keyboard.
